# Infrastructure

Where the website lives, which services it depends on, and what each one
costs. Set up on 16 October 2026.

This repository is public, so this file names services and settings but no
account numbers, logins or passwords. Those stay in the accounts themselves.

## The chain, end to end

```
visitor types www.roniluokkamaki.com
        │
        ▼
  .com registry ──► "ask Cloudflare"           (nameservers, set at Domainhotelli)
        │
        ▼
  Cloudflare DNS ──► "it's at GitHub Pages"    (A + CNAME records)
        │
        ▼
  GitHub Pages ──► serves docs/ from this repository, over HTTPS
```

| Part | Service | What it does | Cost |
|---|---|---|---|
| Domain name | **Domainhotelli** (domainhotelli.fi) | Owns the registration of `roniluokkamaki.com` | 12.90 € first year, then **18.90 € / year** (VAT incl.) |
| DNS | **Cloudflare**, Free plan | Answers "where is roniluokkamaki.com?" | 0 € |
| Hosting + HTTPS | **GitHub Pages** | Serves the `docs/` folder of this repository | 0 € |

Total running cost: **18.90 € a year**, the domain renewal only.

## Domain: Domainhotelli

- Registered **16 October 2026**, paid until **16 October 2027**. Check
  that automatic renewal (*Automaattinen uusiminen*) is on, or renew by hand
  before that date. If a renewal is missed, the site goes offline.
- **Transfer lock** (*Domainin siirtolukitus*) is **on**. Leave it on. It
  stops the domain being moved to another registrar without your say-so.
- **Nameservers** (*Nimipalvelimet*) are set to "use other nameservers":

  ```
  brenda.ns.cloudflare.com
  elias.ns.cloudflare.com
  ```

  This is the one setting that hands DNS over to Cloudflare. Don't change it
  back to Domainhotelli's defaults: Domainhotelli's own DNS is a paid
  add-on (9 € + VAT a year), and without it the domain stops resolving.
- **DNSSEC** is **off**, on purpose. Don't publish DS records unless you
  have also enabled DNSSEC in Cloudflare. A mismatch makes the domain
  unreachable.

## DNS: Cloudflare

The domain's zone is in your Cloudflare account under *Domains →
roniluokkamaki.com → DNS → Records*. It holds exactly these records:

| Type | Name | Content | Proxy status |
|---|---|---|---|
| A | `roniluokkamaki.com` | `185.199.108.153` | DNS only |
| A | `roniluokkamaki.com` | `185.199.109.153` | DNS only |
| A | `roniluokkamaki.com` | `185.199.110.153` | DNS only |
| A | `roniluokkamaki.com` | `185.199.111.153` | DNS only |
| CNAME | `www` | `roniluokkamaki-lgtm.github.io` | DNS only |

The four addresses are GitHub Pages' published IPs. They are the same for
every GitHub Pages site.

**Keep every record on "DNS only" (grey cloud).** Cloudflare's dashboard
nags you to switch on proxying (orange cloud). Don't: a proxied record
hides GitHub behind Cloudflare, and GitHub then can't issue or renew the
site's HTTPS certificate. The site doesn't need Cloudflare's caching or
protection, because GitHub Pages already provides both.

Cloudflare also suggests MX/SPF/DMARC records for email. Email at
`@roniluokkamaki.com` isn't set up, and the site uses the Gmail address,
so these can be ignored.

## Hosting: GitHub Pages

- Repository: `roniluokkamaki-lgtm/nettisivut`, branch `main`, folder
  `/docs` (Settings → Pages).
- `docs/` is generated by `build.py`. Publishing is a git push, which the
  admin tool's **Publish** button does for you.
- The old address `https://roniluokkamaki-lgtm.github.io/nettisivut/` keeps
  working and redirects to the custom domain once that is switched on.

## Switch-over status

| Step | Status |
|---|---|
| Domain registered at Domainhotelli | done 16.10.2026 |
| Owner email confirmation for the domain | **to do by 31.10.2026**, or Domainhotelli suspends the domain |
| DNS records in Cloudflare | done 16.10.2026 |
| Nameservers changed to Cloudflare | done 16.10.2026; Cloudflare emails when the zone is "active" |
| `docs/CNAME` containing `www.roniluokkamaki.com` | to do *after* the domain resolves publicly |
| `SITE_URL` in `build.py` → `https://www.roniluokkamaki.com`, rebuild, push | to do, together with the above |
| GitHub: Settings → Pages → Custom domain, then **Enforce HTTPS** | to do, after the push |
| Optional: verify the domain under your GitHub *profile* Settings → Pages | recommended. It adds one TXT record in Cloudflare and stops anyone else claiming the domain on GitHub |

The order matters. Pushing `docs/CNAME` before the domain resolves makes
the old github.io address redirect to a domain that doesn't answer yet, and
the site looks down.

## Checking it from a terminal

```
nslookup -type=NS roniluokkamaki.com       should list *.ns.cloudflare.com
nslookup roniluokkamaki.com                should list the four 185.199.x.153 addresses
nslookup www.roniluokkamaki.com            should show roniluokkamaki-lgtm.github.io
```

## If the site stops loading

1. **Domain expired or suspended?** Log in to Domainhotelli and check the
   domain's status (*Tila*) and due date (*Seuraava eräpäivä*).
2. **Nameservers changed?** Domainhotelli → *Nimipalvelimet* should still
   show the two Cloudflare names above.
3. **Records changed or proxied?** Cloudflare → DNS → Records should match
   the table above, all grey-cloud.
4. **Site itself broken?** Check whether
   `https://roniluokkamaki-lgtm.github.io/nettisivut/` works and whether
   the latest push succeeded on GitHub (the repository's *Actions* tab shows
   the Pages deployments).
